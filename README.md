# sparkgraph

Spark and reshape graph text streams with deterministic transforms.

**Site:** https://theworker02.github.io/sparkgraph/

## Install / run

```bash
git clone https://github.com/theworker02/sparkgraph.git
cd sparkgraph
node src/cli.js
node --test
```
